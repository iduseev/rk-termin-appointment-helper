# rk-termin-appointment-helper
This repository is for storing an automation bot for booking a consulate appointment in a German embassy.

# Why did I create this script in the first place?
- It's really hard to get a termin these days, if you don't use script or other automatic solutions
- Appointments are only available for a few seconds and usually disappear for weeks
- You will never get an appointment if you don't use some script-like solution
